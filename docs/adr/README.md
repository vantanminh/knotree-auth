# Architecture decisions

Accepted decisions are recorded with the harness CLI in `docs/decisions/`.

| ID | Topic |
| --- | --- |
| 0001 | Host-only session cookie, opaque access tokens, RS256 ID tokens, rotating refresh tokens |
| 0002 | OAuth 2.1 authorization code with mandatory PKCE |
| 0003 | TOTP, email OTP, and hashed recovery codes |
| 0004 | Email provider abstraction and development outbox |
| 0005 | Single super admin locked by environment |
| 0006 | PostgreSQL rate limits |
| 0007 | Visual design of the accounts UI |
| 0008 | Argon2id parameters |
