# Security notes

- Argon2id parameters default to 64 MiB, 3 iterations, parallelism 1. Production refuses less than 19,456 KiB. Hashes are re-computed on login when parameters change.
- Cookies in production are `__Host-knotree_session` and `__Host-knotree_csrf`: `Secure`, `Path=/`, no `Domain`. The CSRF cookie is readable by the page so it can be echoed. The session cookie is `HttpOnly`.
- CORS is an allowlist, defaulting to `APP_BASE_URL`, with credentials. Authenticated responses are `no-store`.
- API CSP is `default-src 'none'`. The Worker sets a page CSP of `'self'` for scripts, styles, and fonts.
- `/metrics` requires `METRICS_TOKEN` in production. Development leaves it open when the token is unset.
- Request ids are generated by the server. Client-supplied ids are not written into the audit log.
- Account deletion anonymizes the primary email, removes password and MFA material, revokes sessions, and keeps security events.
- Do not commit `.env`, `.dev-keys/`, private keys, or provider secrets.
